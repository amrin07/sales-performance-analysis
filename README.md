# sales-performance-analysis
Python and Pandas sales data analysis portfolio
Sales Performance Analysis

Project Overview

An end-to-end data analysis project using Python to explore sales performance across products and cities.

Objectives

- Analyse total and average sales.
- Compare product performance across cities.
- Classify sales performance into categories.
- Identify business trends and opportunities.

Tools & Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Data Visualisation (coming soon)

Analysis Performed

- Data aggregation using "groupby()"
- Sales categorisation using "np.where()" and "np.select()"
- Performance summaries using "value_counts()"
- Product and city comparisons using "pivot_table()"

Business Value

The analysis aims to help sales managers understand product performance, identify strong and weak areas, and make data-driven decisions.

Project Status

In Progress — more analysis, visualisations and business recommendations will be added.
